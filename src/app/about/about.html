I enjoy building the part users don't see: the APIs, the data and the logic that make an app work.

Most of my projects are full-stack: a React interface on the front, a Java and Spring Boot API behind it and a SQL or MongoDB database underneath. On the backend I like designing clear REST endpoints and a clean data model, then testing them with Postman before they reach the front end. Outside the web I've built games in Unity (including VR), Raspberry Pi projects with sensors and desktop apps in WPF and JavaFX, which taught me to pick up new tools fast.

Many of my projects were built in teams, so I'm used to sharing a codebase with Git and GitHub, splitting tasks on Trello and documenting what I build so others can build on it. I'm open to opportunities where I can keep growing as a backend developer.

“Always eager to take on new challenges and collaborate on projects that push the boundaries of what's possible with code.”
